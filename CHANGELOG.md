## 1.0.0

* **Initial Release**: A comprehensive utility package for Flutter.
* **State Management**: Integrated `Riverpod` support with `BaseAppManager` and `AsyncNotifier`.
* **Authentication**: robust authentication infrastructure with `BaseAuthManager` and `BaseAuthApi`.
* **Firebase Integration**: Built-in support for FCM (Messaging), Crashlytics, and Analytics.
* **Network**: Pre-configured `Dio` setup for network requests.
* **Utilities**:
  * `DeviceUtility`: Screen size and platform checks.
  * `DateUtility`: Date formatting helpers.
  * `ContextExtensions`: Responsive design and navigation shortcuts.
  * `StringExtensions`: Validation and formatting tools.
